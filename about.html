About StudioPath Pro

StudioPath Pro is Mohammad Rohaan’s (22I-2327) consolidation of the full Web_Practice coursework into one production-shaped front-end platform — built for discovery calls, classroom defense, and portfolio hunting on GitHub Pages.

Why it exists

Isolated lab folders prove concepts. Clients and recruiters need one URL that filters work, estimates scope, validates intake, and persists planner state — without a backend.

Demo-ready defaults

Light theme is the default for projector rooms and bright offices. Use the demo banner, keyboard D to seed milestones, copy the last estimate, and print a leave-behind PDF.

Concepts on display

Semantic HTML, responsive CSS, DOM scripting, forms & validation, tables, media, dialog lightbox, localStorage, theme tokens, and multi-page navigation — all wired into one narrative product.

What ships in the repo

Only the StudioPath Pro product: index.html, about.html, assets/, js/, docs screenshots, and README — lean for demos and GitHub Pages.

Imagery policy

Hero, team, quote, and documentation screenshots use male portraits, animal mascots, or object photography only — no female stock imagery.

How to pitch it

Open the live site → stay on light theme → seed demo data → run the estimator → break and fix the contact form → show persistence after refresh. Five minutes, full stack of front-end proof.
